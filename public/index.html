This is a demo page to fetch and display data from the Swedavia API. The API has endpoints for departures and arrivals. However it lacks headers to allow Cross Origin Resource Sharing (CORS). As such we cannot call it directly from frontend JavaScript. We therefore use a NodeJS Express server as a relay to call the Swedavia API.

We use Environment Variables to safely store API Keys on the NodeJS Server.

Created by Harold Sikkema in the context of Systems Design in the Interaction Design program at Sheridan College. Fonts via Sharing Sweden.
